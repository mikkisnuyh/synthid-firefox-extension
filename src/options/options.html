SynthID Check

Checks images, video and audio on any website for a SynthID watermark, the invisible mark that Google's AI tools and partners such as OpenAI add to what they generate. The file is handed to Google's official detector at synthid.com, where you sign in and see the result.

How to use

  • Right-click an image, video or audio element and choose Check with SynthID. If a site covers its media with an overlay, right-click the spot and choose Find media under the cursor and check with SynthID.
  • Or click the toolbar button and choose Pick media on this page, then click the media.

Only SynthID watermarks can be detected. If none is found, that doesn't prove the media was made by a person. Text can't be checked.

Drag and drop

If you start dragging from where the box would appear, it shows in the other corner on the same side instead (for example top right becomes bottom right). A new corner applies right away; turning the drop zone on or off applies to pages you open or reload afterwards.

General

Keyboard shortcuts

    Website access

    To check a file, SynthID Check downloads the original from the site that hosts it, which is often a different site than the page you're on (for example an image CDN). That's why it needs access to all websites. Files are only downloaded when you choose to check them.

    SynthID Check can't attach files on synthid.com, so it can't hand a file to the detector.

    To turn website access off, use Firefox's add-ons manager, which controls it.
